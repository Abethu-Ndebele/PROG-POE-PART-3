# PROG-POE-PART-3
Part 3  Stores messages in parallel arrays for sent, disregarded and stored categories. Features: display recipients, find longest message, search by ID or recipient, delete by hash, and generate full report. Supports loading messages from JSON files. Includes validation, error handling and 20 unit tests to ensure all functionality works correctly.

## 📖 Welcome to Connect

**Connect** is a thoughtfully crafted Java application designed to make secure communication accessible and straightforward. Built with care and precision, it combines robust user authentication with an intuitive message management system — proving that powerful technology can also be elegant and easy to use.

## 🚀 Key Features

### 🔐 Secure Access

- **Smart Registration** — Usernames, passwords, and contact numbers are validated with clear, helpful feedback
- **Strong Security** — Passwords meet industry-standard complexity requirements
- **Local Design** — Built for South Africa, with native support for +27 mobile numbers
- **Reliable Login** — Fast, secure authentication with clear status messages

### 💬 Message Centre

- **Unique Identities** — Every message gets its own 10-digit fingerprint
- **Length Control** — 250-character limit with helpful guidance when exceeded
- **Smart Storage** — Messages organised into three intuitive categories: ✅ Sent, ⚠️ Disregarded, 📦 Stored
- **Easy Search** — Find by Message ID or recipient number in an instant
- **Clean Removal** — Remove messages securely using their unique hash
- **Complete Reports** — See everything at a glance, beautifully formatted
- **JSON Ready** — Import messages from external files with ease

- ### ✅ Built to Last

- **60 Unit Tests** — Every feature tested, every edge case considered
- **GitHub Powered** — Automated testing ensures reliability with every update
- **Clean Code** — Readable, maintainable, and built to grow
